# 效果：粒子汇聚

从画布右下椭圆场生成数十颗粒子，沿弧线加速汇聚到图标边缘，接近时变白变亮变大。来源：充电呼吸灯参考 HTML 的 `spawnPoint/makeP/posAt` 与粒子渲染段。

## 效果分解（参考代码的六层语义）

| 层 | 参考代码 | 说明 |
|---|---|---|
| 出生场 | `th=TH0+(TH1-TH0)*pow(rand,0.82)`；`r=rInner+(R-rInner)*pow(rand,0.78)` | 右下椭圆场 `θ∈[-0.50,1.62]`，内圈 `IR+16`，偏向内圈分布 |
| 弧线 | `pos = lerp(S,T,q) + n*sin(πq)*bow`，`bow∈±6` | 每颗走微弯弧线，bow 是法向偏移 |
| 加速 | `v = pace*(26+(120+280*grad)*q^1.7)` | 起步慢、接近图标急加速 |
| 透明度包络 | `0.88*min(smoothstep(0,0.12,q), 1-smoothstep(0.66,1,q))` | 两端淡入淡出 |
| 头部圆点 | `rgba(60+165n, 255, 120+90n, 0.78a)`，半径 `r*(0.7+0.55n)` | 接近时变白变亮变大（n=clamp(q*1.4)） |
| 拖尾 | `len=clamp(每帧位移*9, 1.5, 40)`，三段渐变 | 见《PathEffect描边流动》/《程序化动画Luau脚本》 |

## 路线 A：MCP 烘关键帧（不推荐，仅存档）

40 颗 × 每趟 5 采样 × (x/y/opacity) ≈ 3920 键。能跑，但三个硬伤：**数量翻倍=关键帧翻倍**；**没有拖尾**；**改速度要重烘全部**。

必须遵守《关键帧循环防倒飞》：每趟 `[base, base+L-1]`，下一趟从 `base+L` 起，瞬移帧两端 opacity=0。

## 路线 B：Luau 脚本（定稿方案）

```lua
-- 出生
local th = TH0 + (TH1-TH0) * math.pow(rnd(self), 0.82)
local R  = 1/math.sqrt((c/RX)^2+(s/RY)^2)
local rr = (IR+16) + (R-IR-16) * math.pow(rnd(self), 0.78)
-- 速度
p.q = p.q + p.pace*(26+(120+280*GRAD)*p.q^1.7) * dt / p.len
-- 位置（弧线）
pos = S + (T-S)*q + n*math.sin(math.pi*q)*p.bow
```

绘制：**所有粒子累积进一条 Path，一次 drawPath**（40 颗=1 次调用，不是 40 次）。

## 定稿参数

| 参数 | 值 |
|---|---|
| count | 110 |
| 场 | `RX=RY=116`、`TH0=-0.50`、`TH1=1.62`、`GRAD=0.43` |
| 点半径 | `p.r*(0.7+0.55n)*0.55`（p.r∈0.55~1.4） |
| 颜色 | `rgba(170,255,195,200)` |
| 混合 | additive |

## 注意事项

1. **重生瞬移**：`makeP()` 里必须重置 `px/py` 为新出生点，否则 draw 在重生帧画一条横穿画面的长线；再加位移守卫 `sp > 阈值` 才画尾巴；
2. **alpha 量纲**：`Color.rgba` 是 0–255（见《脚本颜色与透明度量纲》）；
3. **origin**：Image 素材版要先查 `originx/originy`，不是中心就先改锚点（见《画板素材的代码驱动缩放呼吸》）；
4. 关键帧路线的**边界帧覆盖** bug 见《关键帧循环防倒飞》。

## 验收

1. Console/`--screenshot --advance` 帧间 diff ≈ 2000px（粒子在动）；
2. 播放观察：无横穿长线、无倒飞、汇聚到图标边缘即消失；
3. 图标像素逐字节不变（粒子画在图标之后且不透明度受控）。
