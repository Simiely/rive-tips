# 动态效果定义表（SVG）

把"什么时间做什么"画成一页可评审的 SVG 规范表。给设计/开发/未来接手的 AI 看，照着表格能逐帧复刻，不需要打开 Rive。

1. 一页 SVG = 统一时间栅格 + 每元素一行时间块 + 方块内标曲线 + 事件标签带秒数。
2. 时间→x 固定换算（如 500px/s），顶部刻度与竖线**贯穿全表**，竖线即事件时刻。
3. 每个方块内必须写动态曲线名：`linear` / `cubic-bezier(0.42, 0, 0.58, 1)` / `ease-out` / 无补间。
4. 属性一律写**起止值**（`100%→125%`、`trim 0%→100%`、`透明度 100%→0`），不写"放大/缩小"这类模糊词。
5. 按**首个事件时间**排序，先发生的在上；常驻元素排末尾；用语义名（"icon 图形填充"），不用图层编号。

## 一、版式骨架

```
标题栏    画板名 / 尺寸 / 脚本 / Timeline 帧数与时长 / 版本 / 日期
图例      颜色含义（主动作 / 光晕 / 遮罩 / 常驻 / 辉光 / 新增填充发射）
时间栅格  x = 起点 + 秒 × 比例；顶部刻度 + 竖线贯穿到表底
元素块    左侧说明（2–3 行）+ 右侧时间条 + 条带下方事件标签
底部说明  曲线定义 / 时间基准 / 读法 / 关键同步点
```

## 二、坐标与布局常量（本次定稿值）

| 常量 | 值 | 说明 |
|---|---|---|
| 时间轴起点 | x=300 | 左侧 300px 留给说明文字 |
| 时间比例 | 500px/s | 2.4s = 1200px 宽（300 → 1500） |
| 关键竖线 | 1.5px + 强调色 | 卡点（如 1.2s）加粗，其余 1px 灰 |
| 行高 | 106px | 标题基线 +20 / 说明 +38、+54、+70 / 条带 +76~94 / 标签 +108 |
| 说明行距 | 16px | 12px 字号 |
| 条带高度 | 18px | 方块内文字 10px、深色、居中 |
| 条带↔标签间距 | 14px | 更大就显空（34px 实测被要求收紧） |

## 三、内容规则（可复刻的前提）

1. **曲线必标**：分段事件每段方块内写曲线名；无补间写"无补间（瞬时）"。
2. **数值必具体**：`100%→125%`、`trim 0%→100%`、`透明度 100%→0`、`1520px/s`、`α7.5%`。
3. **事件三要素**：动作 + 时间，如「起始 0s」「峰值 125% 1.2s」「移除 1.6s」。
4. **同帧卡点**：多个动作落在同一帧时，底部单独写「关键同步点」列全。
5. **语义命名**：不写 `00001/00002` 这类编号；同一图形的多段填充合并为一块（"icon 图形填充：闪电 0–0.7s，环 0.7–1.2s"）。
6. **两类时间基准分开**：主 Timeline（循环）与其它时基（如 54s 车辆、单颗粒子 1.4s 生命）各占独立行，互不换算。

## 四、防重叠

- 左侧说明每条 ≤ 19 个等效汉字（12px 字号约 200px），超出就换行或缩句。
- 事件标签 2–6 字，相邻标签间距 ≥ 40px。
- 行高不够就加高画布，**不压缩行距**（压缩会叠字）。

## 五、制作流程

1. `queryKeyFrames` 回读真实关键帧：每段起止帧、插值类型、cubic 参数（键 `63/64/65/66`）。
2. 帧 → 秒 → x 坐标，先画栅格与刻度。
3. 逐元素写条带、方块内曲线、事件标签（全部带秒数）。
4. 用 PowerShell 解析校验 XML：`Get-Content x.svg -Raw | ForEach-Object { [xml]$_ }`，能编译即合法。
5. 交付前逐条核对：表中每个数值 = Rive 实际关键帧值，曲线参数也要对得上。
