# 路径电流（追尾流光）与脚本节点跨画板复用

来源：2026-11 车机「003 充电中」实做。路径上一条发光电流从充电图标沿路线追到车尾，车头/车尾跟随路径，光带宽度 2→7 渐变、头尾圆帽、feather 泛光；同时需要脚本原型与交付画板各用一套参数。

> 验证状态：几何/辉光/自适应长度已在本地 2560×1440 CLI 基准与编辑器预览实现；跨画板脚本复用的 `init` 已在控制台确认，最终 `draw` 以编辑器播放为准。改前先提醒用户存快照。

## 一、效果骨架

| 层 | 画法 | 关键参数 |
|---|---|---|
| 底轨 | 整条 `PATH` 折线，`style='stroke'`、round cap/join | 白 `alpha 15/255`、宽 17.5px |
| 泛光 | 同一条光带加宽后再画一次：`width + 2*feather`，`feather`、`blendMode='additive'` | `FX_GLOW_FEATHER`（当前 80）、辉光 `alpha 40~80` |
| 本体 | 原宽度填充，`feather=2`、`srcOver` | 颜色 `#00FF88`、`alpha 255` |

- 光带 = 逐 2px 采样中心线，取法线 `(-sin, cos)`，左右边 `p ± n*w/2`。
- 宽度沿脉冲长度从尾 5px 线性过渡到头 17.5px；头部/尾部各加半圆帽（尾帽从 `+n` 经反切线扫到 `-n`）。
- 顺时针绕序才可见（y 向下）；逆时针填充整条带消失，0 error。

## 二、追车尾与自适应长度

- 车中心弧长 `dist`，车图 229×0.5/2 = **57.25px** 为车尾后退量；`maxDraw = clamp(dist - 57.25, 0, TOTAL)`。
- 脉冲从 `PATH[1]`（画板右下角充电图标旁）出发，在 `maxDraw` 处截断，头部半圆压在车尾，形成「追到尾巴」。
- 长度随车位置自适应（本次定稿）：

```lua
local prog = self.dist / TOTAL                       -- 0..1
local lenScale = prog / 0.5                         -- 10% → 0.2，50%+ → 1.0
lenScale = math.max(0, math.min(1, lenScale))
local pulseLen = self.fxPulse * lenScale             -- 基础参数 fxPulse 仍可调
```

- 宽度渐变的分母必须用**实际脉冲长度** `head - tail`，不能用固定 `fxPulse`，否则脉冲缩短后锥形比例错。
- 脉冲间隔 `fxGap` 不随长度缩放；需要节奏等比再改成 `gap * lenScale`。

> 2026-11-09 定稿更新：电流长度改为**常值**（不再随车进度缩放），推进改为「存进度 + 缓动曲线」，起步快、接近车尾慢；心跳与发射同相位。见 [效果-电流缓动与羽化蒙版.md](效果-电流缓动与羽化蒙版.md)。

## 三、路径与坐标

- 路径顶点角度是**度**（MCP `query_property_values` 的 84/86），Lua 用 `math.cos/sin` 前先 `math.rad`。
- 路径父级与脚本节点必须在同一局部坐标：`移动路径` 父级在 `(1639,682)`，脚本节点也放 `(1639,682)`、100%，`PATH` 表零偏移直接用。
- `PathMeasure:positionAndTangent(d)` 在 **d=0** 时返回的切线**不是单位向量**（实测模长 = 贝塞尔控制柄长度 237.48），必须手动归一化；用烘焙采样表时同样要归一化 `(-ty, tx)`。

## 四、两个画板用不同脚本（MCP 边界）

实测可用的两条路：

| 目标 | 做法 | 结果 |
|---|---|---|
| 同一脚本复用到另一画板 | `duplicate_objects` 复制 `ScriptedDrawable` → `reparent` 到目标画板 → 位置/层序 | `init` 在控制台出现；**不改 848**。最终绘制以预览为准 |
| 不同脚本/不同参数 | `manage_scripts.create` 新建脚本（可带 content）→ **用户在目标画板右键添加脚本节点** | 唯一能真正换绑的方式；MCP 没有 attach 接口 |

关键坑：

1. **`duplicate_objects` 不能复制 ScriptAsset**：报 `Object ... is not a Component`。要用 `manage_scripts.create`，内容可借助 `scripts/rive_mcp.py` 的 `connect/call_text` 从本地文件读取后作为 `content` 传入，避免在对话里塞 28KB。
2. **右键新建的脚本节点落在画板中心 `(1280,720)`、最上层**：必须 `set_property_values` 改到 `(1639,682)`，再用 `reorder_objects` 调到地图之上、UI 之下。
3. **改 848 不重绑**（旧结论仍成立）：不要复制节点后改 `scriptAssetId`；要么同脚本复制，要么手动右键挂新脚本。
4. 新建节点的 `Input` 值是工厂默认；从旧节点复制过来的值（如 `fxGap=200`）不会自动同步，需按 id 回读/写入。

## 五、参数面板（Script Inputs）

- 数值输入 `ScriptInputNumber` 的值键是 **243**；布尔输入 `ScriptInputBoolean` 是 **245**。
- 脚本字段名是面板标签，**只能是 ASCII**：Luau 标识符不支持中文（`速度: Input<number>` 直接报 `Expected type, got Unicode character`）。
- **不要重命名 ScriptInput 对象**成中文：重编译后会被重建（实测 id `291-*` → `297-*`），顺序与值都要重设。
- 想调面板顺序：用 `reorder_objects` 把输入子对象 `sendToFront`（倒序逐个做），声明顺序本身不改面板顺序。
- 中文备注只能写在**源码注释**里（合法、可编译）；每个参数下一行写中文说明，面板仍显示英文。
- ViewModel「中文显示名」方案不属于官方明确的输入标签能力，且 `viewmodel_editor` 写路径在本文件有闪退史；不推荐仅为汉化做 VM。

## 六、坑位清单

| 现象 | 原因 | 处理 |
|---|---|---|
| 光带整条不可见 | 填充绕序逆时针 | 按「-n 尾→头 → 头半圆 → +n 头→尾 → 尾半圆」重排 |
| 尾部是平切、不圆 | 多边形在尾部直接 close | 尾部补半圆（半径=该处宽度一半） |
| 脉冲缩短后锥形比例不对 | 宽度分母仍用固定 `fxPulse` | 用 `head - tail` |
| 辉光改不动 | Paint 在 `init` 创建 | 改常量/重载脚本；或预建两档 Paint 按输入切换 |
| 003 和原型互相影响 | 共用同一个 scriptAsset | 新建脚本 + 右键挂节点，各用各的 |
| 新节点位置不对 | 右键创建落在画板中心 | 设 `(1639,682)` 并调层序 |
| 面板输入顺序乱 | 输入对象子级顺序 | `sendToFront` 倒序重排，回读 children 核对 |
| 输入中文标签丢失 | 改了输入对象 name | 不要改名；中文写源码注释 |

## 七、实测

- 本地基准 2560×1440、600 帧：底轨+本体+泛光完整效果 render 1.258ms，空场景 0.965ms，净增 **0.293ms/帧**（p95 +0.435ms）。
- 路径 24 顶点、总长 2701.79px；车图 95×229 @50%，车尾后退 57.25px。
- 追踪参数：脉冲 675、间隔 750（可在面板改，本次 003 改为 200）、头宽 17.5、尾宽 5、速度 500px/s。
