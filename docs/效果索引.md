## 选型：一个效果用哪条路线

```
效果需要的是…
├─ 自绘几何（粒子/光圈/辉光叠加） → Node 脚本（程序化，参数化最好）
├─ 素材真实轮廓的变形/截取        → PathEffect 脚本（唯一能读 PathData 的协议）
├─ 素材的缩放/位移（循环呼吸）     → 空时间线关键帧（最简，零脚本依赖）
└─ 素材的逐帧实时公式/非循环       → 组件画板 + Input<Artboard> + 脚本 transform
```
