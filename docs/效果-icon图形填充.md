# icon 图形填充（液面上升 + 描边绕行）

在图标内部做"从下往上填满"的充能效果。两个独立方案各管一类形状，可同一时间轴串联。

1. **不规则闭合图形（闪电）用渐变液面**：复制图形 + 垂直线性渐变，顶部透明 → 底部亮色，两个**同位置 stop** 形成硬切液面；动画 stop position `100%→0`。
2. **不要用顶点动画做填充**：压缩/缩放顶点会让形状变形，看起来像"图像翻转"（实测失败，已弃用）。
3. **半缺圆环用原生 Trim 绕行**：真实路径 + `addTrimPaths`，动画 trimEnd `0%→100%`；键 `114`=trimStart / `115`=trimEnd / `116`=trimOffset。
4. **`path_editor.createShapes` 建的路径默认 `isclosed=true`**：弧线会被自动闭合，缺口被填满并伸出边界；必须显式设开放路径。
5. **环端点角度用真实顶点反算**（`atan2`），截图像素扫描估算会偏 3–4°，视觉越界。

## 一、两方案对照

| | 渐变液面 | Trim 绕行 |
|---|---|---|
| 适用 | 任意闭合图形（闪电、图标整体） | 描边路径（环、轮廓线） |
| 原理 | 渐变 stop 位置动画 | trimStart / trimEnd / trimOffset |
| 形状变形 | 无 | 无 |
| 视觉 | 水平硬切线上升 | 沿路径推进 |
| MCP 支持 | ✅ 建渐变 + 打点 | ✅ `addTrimPaths` |

## 二、渐变液面（涨水效果）

1. 复制原图形做高亮层（`duplicate_objects`），放同父级、原图之上，跟随缩放。
2. 加 `Gradient.linear` 填充，角度 90°（垂直）。
3. **两个 stop 同位置**：上 stop 透明、下 stop 亮色 → 中间形成一条硬切液面；有间隙就会变成模糊过渡带。
4. 渐变覆盖范围要大于图形高度并留余量（实测 `-30 ~ 30` 覆盖 icon 内环 + 闪电双图形）。
5. 动画 stop position `100 → 0`：液面从底升到顶；配 `cubic-bezier(0.42, 0, 0.58, 1)` 缓入缓出。
6. stop position 的属性键**按对象查**（`query_property_keys`），不同 GradientStop 编号不一致，不要硬编码。
7. 填满后整层 opacity 淡出（能量释放），图标回到基础色。

## 三、Trim 绕行（半缺环）

1. 从原环**顶点数据**算缺口两端极角（`atan2`），用真实角度重建弧线；本次缺口 179°–203°，弧 331°。
2. `createShapes` 建路径后**立即把 `isclosed` 设为 false**（默认 true）；否则两端被直线连上，缺口消失。
3. `addTrimPaths`：`paintIds` 传 **Fill/Stroke 子对象 id**（不是 Shape id）；一个 paint 只能有一个 trim，重复添加会被拒，调参用 `set_property_values`。
4. 初始 trimEnd=0（隐藏），动画 `0→100` 沿路径填满；`offset` 可控制起点旋转。
5. **平头 cap**（butt）：圆帽会让两端探进缺口，视觉越界。
6. 三层叠加：暗色底环（常驻）+ 宽羽化辉光（alpha 25%–40%、feather 8）+ 亮色核心（实心）。
7. 辉光层与核心层的关键帧必须同步（删中间帧合并曲线时，两层都要改）。

## 四、时间轴卡点（003 充电中定稿）

Timeline 1 = 144 帧 / 2.4s：

| 帧 | 事件 | 曲线 |
|---|---|---|
| 0–42 | 闪电液面 100→0 | cubic (0.42, 0, 0.58, 1) |
| 42–72 | 环 trimEnd 0→100 | cubic (0.42, 0, 0.58, 1) |
| 0–12 | 图标放大 100→125% | cubic |
| 72 | 填充完成 + 缩放峰值 125% + 发射 | — |
| 72–85 | 绿色淡出（透明度 100→0） | cubic (0.42, 0, 0.58, 1) |
| 72–143 | 回落 125→100% | cubic |

要点：**填充完成帧 = 缩放峰值帧 = 发射帧**，三个动作同帧对齐；所有填充段统一缓入缓出。

## 五、验收

- 静态定格：`set_property_values` 把 stop position / trimEnd 设到中间值 → `capture_artboard`，确认液面水平、弧段不越界。
- 缺口验证：像素扫描按极角统计覆盖角度（本次绿色 331°，缺口 179°–203° 空白）。
- 默认态：不播放时 trimEnd=0、高亮层 opacity=0，图标为原色，无残留。
