# 效果：脉冲辉光与呼吸灯

图标背后常亮的绿色辉光：心跳打点（快胀缩）+ 慢呼吸（长周期）+ 常亮底光。来源：参考 HTML 的 `radialGlow()` 与 `pulse = sin³`。

## 效果分解

| 层 | 参考代码 | 语义 |
|---|---|---|
| 心跳 | `pulse = sin³(2πt/0.75)` | 前 0.375s 打完，后半秒停 |
| 半径 | `IR*1.15 + pulseAmp*pulse` | 光晕随心跳胀缩 |
| 底光 | `radialGlow(..., strength*pulse)` 叠加在常亮之上 | 灯常亮，心跳时更亮更大 |
| 慢呼吸 | 本文补充：±5% 半径 @2.4s | 参考没有，车机版需要"呼吸灯"语义 |

**设计约定（用户定稿）**：脉冲**只变尺寸、不变透明度**；透明度恒定、足够淡。

## 路线 A：脚本（定稿，24 层薄叠加）

MCP 写渐变不可靠（`setPaints` 带 alpha 停靠点 → `paint: null`），平滑衰减用**N 层同心薄圆 + additive**：

```lua
-- 恒定亮度，只有半径进公式；24 层薄叠加保证边缘连续
local sv    = math.sin((self.t / PULSE_PERIOD) * math.pi * 2)
local pulse = sv > 0 and sv*sv*sv or 0
local breath = 0.05 * math.sin((self.t / 2.4) * math.pi * 2)   -- 慢呼吸
local base   = (IR * 1.15) * (1 + 0.26 * pulse) * (1 + breath)
for i = 1, 24 do
    local f = 1.34 - 0.84 * (i / 24)      -- 半径 1.34x → 0.50x 连续过渡
    self.glowPath:reset()                  -- reset 只在绘制前（Path 铁律）
    addCircle(self.glowPath, 0, 0, base * f)
    renderer:drawPath(self.glowPath, self.glowPaint)
end
```

平滑条件：层间半径差 <2px、每层 alpha ≤3/255。中心累积 = `1-(1-a)^24`。

## 路线 B：素材 + 空时间线关键帧（交付板用）

辉光是现成 Image（origin 已是 50,50 中心）时，**不建脚本**，直接在画板空时间线打缩放键（详见《画板素材的代码驱动缩放呼吸》）：

- 2.4s 循环、3 次心跳（每 0.8s 一次）、scale `base → +15% → base`，sin³ 打点 0/6/12/18/24 帧一个峰；
- origin 不是中心就先改 `originx/originy`，否则光心偏移；
- 透明度不参与（用户约定）。

## 定稿参数

| 参数 | 脚本版 | 素材版 |
|---|---|---|
| 每层 alpha | 2/255（中心累积 ≈0.17） | 素材自带 |
| 半径/缩放 | `33.4 → 42.1`（+26%） | `50.03% → 57.54%`（+15%） |
| 心跳周期 | 0.75s | 0.8s |
| 慢呼吸 | ±5% @2.4s | 循环即 2.4s |

## 注意事项

1. **alpha 量纲 0–255**（见《脚本颜色与透明度量纲》）——"看不见"先查量纲再查渲染；
2. **Path 铁律**：`reset` 只在绘制前；24 层每次 `reset→画→drawPath` 是合规循环；
3. **paint 只读**：要不同亮度档就 init 里预建多支 Paint，draw 里切引用不改色；
4. **验收判据**：峰值帧与静止帧的**图标像素逐字节不变**（辉光在图标之后、不透明度受控）；沿半径采样剖面单调递减、相邻步差 ≤3/255；
5. 底光丢失的排查：呼吸动画可能还在缩放一个**空组**（组内圆盘已删）——查组的孩子。
